🐝 BeeWatch – Movie & TV Show Recommendation System

BeeWatch is a full-stack MERN application that provides personalized movie and TV show recommendations. It integrates the TMDB API to fetch real-time data, offers secure user authentication, and delivers an elegant, responsive UI built using Vite + React.

🚀 Features

🔐 User Authentication (Signup, Login, Logout) with JWT & Secure Cookies

🔎 Search movies & TV shows

🎬 Watch Page with similar & recommended sections

👤 Actor/Person Page with movies, TV credits, and images

📊 Real-time data fetched from the TMDB API

🧠 Question-based movie recommendation (future-ready)

📱 Fully responsive and visually engaging UI

⚡ Built using Vite for blazing-fast frontend performance
